# Field Notes

**The wild things of ordinary places**

Photography and field notes from the water's edge — Tampa, Pasco County, and the small wild places in between.

Live site: https://nicofoxheart.github.io/Nicolas-Graham-Nature/

Photographs, field notes & art direction by Nicolas Graham · 3D site built with Claude Code

Portfolio: https://nicofoxheart.github.io/Nicolas-Graham-portfolio-/

## What each file is

| File | What it is |
|---|---|
| `index.html` | The whole site: the text, the layout, the photo viewer, the sound button and the 3D desk. |
| `hero-01.jpg` | The opening photo (Tampa Riverwalk). |
| `plate-01.jpg` … `plate-06.jpg` | The Residents photos. |
| `aq-*.jpg` (9 files) | The Aquarium photos. |
| `ec-*.jpg` (4 files) | The eclipse photos. |
| `infinite-love.mp3` | The ambient music behind the Sound button (Nicolas's own track). It only plays after a click. |
| `og.png` | The preview picture shown when the link is shared. |
| `.nojekyll` | An empty file that tells GitHub Pages to serve the files as they are. |
| `README.md` | This note. |

## How to swap a photo

Replace the file with a new one that has **exactly the same file name** (for example, a new `plate-03.jpg`). Keep the
same rough shape (portrait stays portrait) so the page layout does not change. The descriptions (alt text) and captions
live in `index.html`; edit them there if the new photo shows something different.

## Good to know

- The 3D desk needs a modern browser with WebGL. Where that is not available, the site shows a still image instead, and
  all the text, photos, the photo viewer and the sound button still work.
- The 3D library (three.js 0.160.0) loads from jsdelivr, and the fonts load from Google Fonts.
